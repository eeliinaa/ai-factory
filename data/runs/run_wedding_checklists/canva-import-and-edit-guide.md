Canva Import & Edit Guide

1) Upload the provided PPTX to Canva:
   - Sign into Canva > Home > Create a design > Import file > Upload PPTX.
2) Once uploaded, open the design in Canva editor. Pages will appear as editable slides.
3) Edit text and contact fields: click text boxes to update vendor names, phone numbers, and kit owner.
4) Change colors: use the color picker to set the accent color on elements; adjust background if needed.
5) Replace icons or images: click the icon > Replace > Upload or use Canva elements.
6) Export settings for print:
   - Choose 'Download' > File type: PDF Print
   - Select 'Crop marks and bleed' if available
   - Resolution: default PDF Print (sufficient for 300 DPI export)
7) For pocket cards and tags:
   - Ensure you arrange multi-up pages on an 8.5x11 or A4 canvas before downloading
   - Use 'Crop marks and bleed' to get cut lines

Tips:
- If text shifts during import, check slide masters in the PPTX and simplify complex layers.
- For buyer-facing instructions, recommend downloading as 'PDF Print' and using a professional printer for sticker paper or heavy stock.
